# Open MMD In Changed · 命名与资产规范

> 本文件是**唯一权威**的命名与资产规范。所有新增形态、贴图、动画、材质配置都必须
> 遵守这里的规定。与本文冲突的写法（例如历史遗留的 `_emi.png`）一律视为**不合规**，
> 新资产不得沿用。
>
> 本文面向：**新增一个 MMD 形态**、**替换贴图/动画**、**接入第三方模型**。附录列出
> 当前内置模型 `mmd_latex` 的资产清单（该模型已冻结，文件名与 PMX 内部路径绑定，
> 不做改名，仅作为对照样例）。

---

## 1. 命名总览（一个形态 = 一套 ID）

假设新形态叫 `cyan_fox`，则下列所有 ID 必须**同名不同后缀**，且保持一致：

| 用途 | 值 | 说明 |
|---|---|---|
| 实体 ID | `openmmdchanged:cyan_fox` | 注册表 `EntityType` |
| TransfurVariant ID | `openmmdchanged:cyan_fox` | 玩家变身形态，**与实体 ID 相同** |
| 刷怪蛋 ID | `openmmdchanged:cyan_fox_spawn_egg` | `实体ID + _spawn_egg` |
| 固定模型文件夹 | `openmmdchanged.cyan_fox` | 给 MMDSkin 的运行目录句柄 |
| JAR 资源目录 | `assets/openmmdchanged/mmd/cyan_fox/` | 同 ID 的小写目录 |
| 运行缓存目录 | `.minecraft/3d-skin/EntityPlayer/openmmdchanged.cyan_fox/` | 由安装器生成，勿手动改 |
| 语言键（实体） | `entity.openmmdchanged.cyan_fox` | 中文：青狐胶兽 |
| 语言键（蛋） | `item.openmmdchanged.cyan_fox_spawn_egg` | 中文：青狐胶兽刷怪蛋 |

**铁律**

- ID 只允许小写英文字母、数字、下划线 `_`、短横线 `-`、斜杠 `/`。禁止中文、空格、大写。
- 实体 ID 与 Variant ID 必须相同（Changed 用同一个 id 关联实体与形态）。
- 模型文件夹名用 **`openmmdchanged.` + ID**（点号），资源目录名用 **`文件名.md/`**（ID 原样小写）。
- `<模型目录>/anims/` 里的动画文件名是固定动作名，见第 4 节。

## 2. 资源目录结构规范

每个固定形态的模型资源统一放在：

```text
src/main/resources/assets/openmmdchanged/mmd/<id>/
├── asset.list                 # 必须存在的清单，逐行列出全部文件（第 5 节）
├── model.pmx                  # 主模型（PMD 也支持，新模型一律 PMX）
├── model.properties           # 模型缩放/背包预览缩放（第 6 节）
├── secondary_motion.json      # 可选；仅当 PMX 无刚体时生效
├── liltoon_materials.json     # 可选；逐材质 lilToon 参数（第 7 节）
├── <材质>.png                 # 基础贴图（每材质一张，或共用）
├── <材质>_eye.png             # 面部/眼片贴图（可选）
├── <材质>_emission.png        # 独立发光贴图（可选）
├── liltoon_<材质>_normal.png  # 法线贴图（可选，暂未渲染）
└── anims/
    ├── idle.vmd
    ├── walk.vmd
    ├── sprint.vmd
    ├── sneak.vmd
    └── die.vmd
```

**分层原则**

1. **基础色（Base Color）** 只放颜色，独立一张 PNG。**不要**把发光烘焙进来。
2. **发光（Emission）** 永远单独一张 `<材质>_emission.png`，与该材质 Base Color 同尺寸、
   同 UV、同原点；非发光区域必须是 `RGBA(0,0,0,0)`。
3. **眼睛** 用 `<材质>_eye.png`（运行时自动替换面部材质的贴图）。虹膜/眼白要落在该图的
   对应 UV 区域。
4. **法线** 用 `liltoon_<材质>_normal.png`。当前渲染器**只记录不渲染**，接入时仍需放好以待将来启用。

## 3. 贴图命名规范

贴图文件名由 **PMX 材质语义** 派生，全小写、下划线分词，不用空格连字符混用。

| 类型 | 命名 | 对应 PMX 材质 | 说明 |
|---|---|---|---|
| 基础色 | `<材质>.png` | `Body` → `body.png` | 一材质一图；共用的按材质名区分 |
| 眼睛 | `<材质>_eye.png` | `Body` → `body_eye.png` | 运行时按 `_eye.png` 后缀识别面部 |
| 发光 | `<材质>_emission.png` | `hair` → `hair_emission.png` | 必须独立图；`_emission` 是唯一合法后缀 |
| 法线 | `liltoon_<材质>_normal.png` | `clothes` → `liltoon_clothes_normal.png` | 由 Unity 导入器生成 |
| 法线（切线空间变体） | `liltoon_<材质>_t_normal.png` | `clothes_t` → `liltoon_clothes_t_normal.png` | 同上，仅当材质有 T 变体 |

**强制规则**

1. **发光后缀只有 `_emission`**。历史遗留的 `_emi`、`_emi.png` 一律作废，新资产禁用。
2. 文件名区分大小写，且必须与 `liltoon_materials.json` 和 `asset.list` 完全一致。
3. 基础色与发光图必须：**同尺寸、同 UV、同画布原点**；推荐 2048×2048 RGBA PNG、非索引色。
4. 不发光像素 RGB 也要清零（置 `RGBA(0,0,0,0)`），避免缩放/过滤产生彩边。
5. 发光不靠文件名或颜色自动触发。必须由 `useEmission: true` + 明确的 `emissionTexture`/
   `emissionLayers` 显式声明（见第 7 节）。仅放一张 `_emi.png` 不会让任何东西发光。
6. 颜色筛选（`cyan`/`color`/`$base`）只作为**无源文件时的迁移后备**，发布前必须替换为
   独立蒙版贴图。

## 4. 动画命名规范

`<模型目录>/anims/` 下，动作文件名 = 固定动作名（不受模型、语言影响）：

```text
idle.vmd       站立
walk.vmd       行走
sprint.vmd     疾跑
sneak.vmd      潜行
die.vmd        死亡
swim.vmd       游泳（可选）
swingLeft.vmd  左手攻击（可选）
swingRight.vmd 右手攻击（可选）
ride.vmd       骑乘（可选）
```

- 位置大小写敏感，且必须在 `asset.list` 中逐行列出，否则不会被安装到运行目录。
- 缺少的动作由 MC-MMD-rust 默认动画兜底，但骨骼命名必须兼容（见接入指南 3.3 节）。
- 渐变兽化阶段**不需要** VMD；它使用 Changed 原版动画，完成兽化后才切到 PMX。

## 5. `asset.list` 清单规范

`<模型目录>/asset.list` 是一个逐行清单，**漏写的文件不会被安装**，即使它存在于 JAR 中。
路径大小写必须与实际文件完全一致，用相对路径，行首 `#` 为注释。

```text
model.pmx
model.properties
body.png
body_eye.png
body_emission.png
hair.png
hair_emission.png
liltoon_materials.json
liltoon_clothes_normal.png
secondary_motion.json
anims/idle.vmd
anims/walk.vmd
anims/sprint.vmd
anims/sneak.vmd
anims/die.vmd
```

**检查姿势**：新增/改名文件后，先更新文件本身，再把文件路径加进 `asset.list`。
`MmdAssetInstaller` 只拷贝 `asset.list` 里列出的文件，`asset.list` 没写 = 模型找不到。

## 6. `model.properties`

控制模型显示尺寸，与碰撞箱无关（碰撞箱在 `EntityType.Builder.sized()` 里设置）。

```properties
size=1.53              # 世界/实体/玩家显示倍率
size_in_inventory=1.53 # 背包预览倍率
```

## 7. `liltoon_materials.json` 命名与最小配置

按 **PMX 材质名** 组织。材质名不同可用 `aliases` 桥接（匹配顺序：PMX 材质名 → aliases →
基础贴图文件名）。只有列出来的材质才生效，**未列出的材质默认不发光、用兼容参数**。

```json
{
  "Body": {
    "useEmission": true,
    "emissionTexture": "body_emission.png",
    "emissionLayers": [
      { "texture": "body_emission.png", "maskMode": "texture", "strength": 1.0 }
    ],
    "useOutline": true,
    "outlineWidth": 0.1,
    "outlineColor": [0.20, 0.24, 0.32, 1.0]
  }
}
```

- `emissionTexture` 用于原生/GPU 后端；`emissionLayers` 用于 Minecraft 缓冲渲染后端。
  两者通常写同一张合成图。
- 完整参数表与发光规则见 `docs/lilToon移植分支说明.md`。

## 8. 不应做的事（违规清单）

| ❌ 违规 | ✅ 正确做法 |
|---|---|
| 放 `Body_emi.png` 指望自动发光 | 放 `body_emission.png` 并在配置里 `useEmission: true` |
| 把发光烘焙回 Base Color | 基础色只放颜色，发光单独一张 |
| 给不发光材质开 `useEmission` | 只有真发光的才开；`baseLightFloor` 不是发光 |
| 用 `cyan`/`color` 颜色筛选用到底 | 正式资产用独立蒙版贴图 |
| 在 Java 里硬编码材质名/骨骼序号 | 写进该模型自己的 `liltoon_materials.json` |
| 两个形态共用同一模型文件夹 | 一形态一只读文件夹，避免缓存互相覆盖 |
| 用中文/大写注册 ID | 全小写 + 下划线/短横线 |

## 9. 当前内置模型 `mmd_latex` 资产清单（对照样例，已冻结）

本模型已发布、文件名与 PMX 内部路径绑定，**保持现状**。下面只做说明，不用于改名。

```text
assets/openmmdchanged/mmd/mmd_latex/
├── asset.list
├── model.pmx
├── model.properties
├── secondary_motion.json
├── liltoon_materials.json

├── Body_eye.png        # 眼睛
├── Body_emission.png   # 发光（Body）
├── clothes.png         # 基础色（材质 clothes）
├── hair.png            # 基础色（材质 hair）
├── hair_emission.png   # 发光（hair）
├── tail.png            # 基础色（材质 tail）
├── tail_emission.png   # 发光（tail）
├── liltoon_clothes_normal.png
├── liltoon_clothes_t_normal.png
└── anims/{idle,walk,sprint,sneak,die}.vmd
```

> 注意：`Body.png` 首字母大写、其余小写，是历史 PMX 材质名决定的**不一致**。新资产统一

> `hair_emi.png`、`tail_emi.png` 均属**已废弃、未被引用**的历史文件，规范中不再出现。
